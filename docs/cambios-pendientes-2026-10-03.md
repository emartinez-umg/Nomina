La referencia es `Cambios_pendientes_modulo_Nomina.pdf`; las rutas y tecnologías propuestas allí no se tomaron como instrucciones para sustituir el proyecto. ## Instalación y acceso

`npm run db:workflow` aplica la migración aditiva y crea el primer administrador si hace falta. La contraseña temporal se escribe únicamente en `.nomina-admin-inicial.txt`, excluido de Git y con permisos 0600. El primer ingreso exige cambiarla. Reiniciar la API después de la actualización.

Las tablas ERP originales se mantienen; existen 194 tablas base y 9 complementarias. Los nuevos datos de sesiones, correlativos, preferencias, asuetos y recomendaciones se guardan en cinco tablas adicionales a las cuatro de seguimiento existentes.

## Comprobación

- `npm test`: validaciones, permisos compartidos, fechas, NIT, versiones, borradores y contraseñas.
- `npm run test:oracle`: 51 formularios, 53 catálogos, restricciones, alta atómica y separación por empresa.
- `npm run test:workflow`: conciliación, vacaciones, pagos, baja, auditoría, login, cambio de contraseña, permisos, privacidad, conflictos de edición, correlativos concurrentes, períodos y diez casos sintéticos.
- `npm run test:init`: instalación SQL nueva e idempotencia de catálogos.
- `npm run build`: metadatos, guía y compilación frontend.
- Verificación manual de navegador sobre esquema temporal: login, contraseña inicial requerida, recorrido, alta con código bloqueado y borrador recuperado tras recargar.

## Decisiones que faltan

Confirmación del ingeniero sobre el reparto salarial; plantilla oficial del libro de salarios; edad mínima aplicable; contrato de campos empresariales ausentes y política de publicación de cumpleaños. Ninguna de esas decisiones se asumió silenciosamente.
